# Theme resource attribution

This directory contains a deliberately limited set of theme-scoped system icons supplied by the project owner for THEME-11 and THEME-12.

| Directory | Source archive path | Bundled provenance statement | Use in this project |
|---|---|---|---|
| `win98/` | `windows_98/windows-98-main/` | The archive’s `readme.txt` identifies the Windows 98 Main Icon Set as released to the public domain and links to `https://www.rw-designer.com/icon-set/windows-98-main`. | System-adjacent Windows 98 icon treatment only. |
| `winxp/` | `windows_xp/` and `windows_xp/windows-xp-folder/` | The archive’s readmes identify the Windows XP Desktop and Folder Icon Sets as released to the public domain and link to `https://www.rw-designer.com/icon-set/windows-xp-desktop` and `https://www.rw-designer.com/icon-set/windows-xp-folder`. | System-adjacent Windows XP icon treatment only. |

The archives’ registry files, sound schemes, macOS metadata, and any files not copied here are intentionally excluded. These icons are not used as a Microsoft brand mark, and original portfolio application icons remain the primary navigation assets.
